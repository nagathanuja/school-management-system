# 🏫 School Management System

A simple School Management System developed using HTML, CSS, JavaScript, Node.js, and Express.js. This project allows users to manage student information, teacher information, and student attendance through a simple web interface.

---

## 📌 Features

- 👨‍🎓 Student Management
- 👨‍🏫 Teacher Management
- 📅 Attendance Management
- 🏫 School Dashboard
- ➕ Add Students
- ➕ Add Teachers
- 📋 View Student Records
- 📋 View Teacher Records
- ✅ Mark Student Attendance
- 🌐 REST API using Express.js

## 🚀 How to Run

### 1. Clone the repository

bash
git clone YOUR_GITHUB_REPOSITORY_LINK


### 2. Open the backend folder

bash
cd School-Management-System/backend


### 3. Install dependencies

bash
npm install


### 4. Start the server

bash
npm start


### 5. Open the website

Open your browser and go to:

text
http://localhost:3000
